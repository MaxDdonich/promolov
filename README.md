# PromoLove

Постоянная версия: **https://maxddonich.github.io/promolov/**

Сайт-агрегатор промокодов на доставку еды. Сам собирает коды с открытых
сайтов-агрегаторов, считает **реальную выгоду** под ваш чек и раскладывает
предложения по подборкам.

Работает без сборки, Node.js и Python — только HTML/CSS/JS и PowerShell для
локального сервера и сборщика.

## Как запустить

### Вариант 1. С автоловом (рекомендуется)

Запустите `Запустить с сервером.bat` или:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\serve.ps1
```

Откройте `http://localhost:8787/`.

Сервер:
- при старте запускает `collector.ps1`, если `data/codes.json` старше 30 минут;
- каждые 30 минут обновляет фид в фоне;
- отдаёт сайт и JSON с заголовком `Access-Control-Allow-Origin: *`;
- слушает `0.0.0.0:8787`, поэтому доступен другим устройствам в той же сети;
- поддерживает несколько одновременных запросов и gzip.

Сайт при загрузке сам подключает `data/codes.json`, кэширует коды в
`localStorage` и обновляет фид каждые 15 минут. Кнопка «Подключить / обновить»
в панели «Источники» запускает обновление вручную.

### Доступ с телефона и других устройств (LAN)

В консоли сервера после запуска будет два адреса:

```
this computer: http://localhost:8787/
LAN / Wi-Fi:   http://192.168.x.x:8787/
```

Вторая ссылка работает на телефоне и других компьютерах в той же Wi-Fi-сети.
На сайте её можно скопировать кнопкой **↗** в шапке или в панели
«Источники → Доступ с других устройств».

Если ссылка не открывается:

1. Устройства должны быть в одной сети, а Wi-Fi — не «гостевой» с изоляцией клиентов.
2. Запустите `Разрешить в брандмауэре.bat` (нужен администратор) — он добавит
   входящее правило для TCP 8787.
3. Проверьте, что в адресе стоит IP компьютера, а не `localhost`. `localhost`
   на телефоне указывает на сам телефон, поэтому и была ошибка.

### Публичная ссылка (интернет)

Запустите `Публичная ссылка.bat` (или `powershell -File .\tunnel.ps1`).
Скрипт поднимает SSH-туннель через `localhost.run`, печатает HTTPS-адрес вида
`https://....app.lhr.life` и копирует его в буфер обмена.

- Ссылка работает с любого устройства, пока окно туннеля открыто.
- Бесплатный адрес периодически меняется; после перезапуска скопируйте новый.
- Нужен SSH-клиент Windows (обычно уже включён в Windows 10/11).
- Трафик идёт через внешний сервис туннеля: не открывайте через публичную ссылку
  ничего конфиденциального. Остановить — `Ctrl+C` в окне туннеля.

### Вариант 2. Без сервера

Откройте `index.html` двойным щелчком (`Открыть ПромоЛов.bat`). Интерфейс
заработает, но браузер на `file://` обычно не даёт читать локальный JSON,
поэтому реальный фид и автозагрузка доступны только через сервер. Ранее
закэшированные коды при этом остаются.

### Постоянный хостинг: GitHub Pages

В репозитории есть workflow `.github/workflows/update-feed.yml`. Он каждые 30 минут
запускает `collector.ps1` на GitHub Actions, обновляет `data/codes.json` и коммитит
его обратно. GitHub Pages отдаёт статический сайт без вашего компьютера.

После публикации адрес:

```
https://maxddonich.github.io/promolov/
```

Сайт работает 24/7, пока живы GitHub Pages и Actions. Компьютер, `serve.ps1` и
туннель для этого не нужны. Если источник промокодов недоступен из GitHub,
обновится только фид — сам сайт продолжит работать.

  Grow Food, Level Kitchen, Elementaree, Just Food, BeFit и др.
- **Доказательная проверка** — каждый код получает `confidence` 0–100 и статус
  `confirmed` / `likely` / `single`. Учитываются независимые источники, история
  появления кода, популярность у источника, срок действия и совпадения между
  сайтами. Подтверждённые коды поднимаются вверх.
- **История и здоровье источников** — `data/state.json` хранит firstSeen/lastSeen/
  seenRuns, а `data/source-health.json` — сколько кодов даёт каждый источник и
  какие были ошибки. Упавший источник не стирает коды мгновенно.
- **Автоподключение фида** — `data/codes.json` загружается при старте без
  нажатий, кэшируется в `localStorage` и обновляется по таймеру.
- **Калькулятор выгоды** — считает скидку с учётом лимита, минимального чека
  и стоимости доставки, а не просто показывает процент.
- **Индекс выгоды 0–100** — скидка + минимальный чек + свежесть + уверенность.
- **Подборки** — «Только подтверждённые», «Москва», «Только в городах»,
  «Уже пользовался сервисом», «Скидка на всю корзину» и «Собрано с сайтов».
- **География** — сборщик вытаскивает города из условий, показывает их бейджем
  и умеет оставить только коды для Москвы или только городские акции.
- **Честные статусы** — «Подтверждён», «Вероятно рабочий», «Один источник»,
  «Истёк». Код не называется «проверенным», если реальной проверки не было.
- **Источники у каждого кода** — в деталях видно, какие сайты/каналы подтверждают
  код, сколько раз его видели и когда последний раз.
- **Фильтры** — сервис, подборка, «только подтверждённые», «только выгодные»,
  бесплатная доставка, избранное, поиск, сортировки.
- **Голоса** «сработало / не сработало» — дополняют автоматическую уверенность.
- **Демо-автолов** — встроенный пул «пойманных» кодов для живой анимации,
  если фид недоступен.

### Как устроены подборки

Подборки можно выбирать **несколько одновременно**. Они работают как пересечение:
код должен подходить под все выбранные. Например, «Москва» + «Уже пользовался
сервисом» оставит только коды, доступные в Москве и без ограничения «только первый
заказ». «Все коды» сбрасывает выбранные подборки.

- **Уже пользовался сервисом** — `existingUsers: true`. У кода нет условия
  «только для новых клиентов», его можно применить на аккаунте с историей заказов.
- **Скидка на всю корзину** — `wholeCart: true`. Скидка действует на весь заказ,
  а не на отдельное блюдо, категорию, раздел или только доставку.
- **Собрано с сайтов** — коды, полученные из JSON-фида, а не из демо-базы.
- **Москва** — коды, доступные в Москве: общероссийские плюс те, где в `cities`
  есть «Москва» или «Московская область».
- **Только в городах** — коды с явным ограничением по городам (`cityRestricted: true`).

Флаги независимы. Счётчики подборок пересчитываются с учётом остальных фильтров.

## Рабочие коды, статусы и тёмные карточки

Статус считается по сроку, источнику и отметкам пользователей:

| Статус | Как получается | Виден при «только рабочие» |
|---|---|---|
| Рабочий | 5+ отметок, ≥ 70% «сработало» | да |
| Свежий из источника | код только что собран из фида, отметок ещё нет | да |
| Спорный | 45–70% успешных | нет |
| Не работает | меньше 45% успешных или истёк срок | нет |
| Демо-пример | код из встроенной демо-базы | нет, если загружен реальный фид |

- **«Проверить» в шапке** заново загружает фид и пересобирает выдачу. Коды,
  которых больше нет в источнике, исчезают.
- **«Проверить» в карточке** перезапрашивает фид и подтверждает, что код всё ещё
  есть в источнике. Это не гарантирует срабатывание при оплате: публичного API
  проверки промокодов у сервисов нет, окончательную проверку делает только корзина.
- **Тёмная карточка — не нерабочий код.** Она затемнена, когда сумма вашего чека
  меньше минимального заказа по этому коду. Светлая карточка — код можно применить
  при текущем чеке. Минимальный чек указан в блоке под кодом.
- Если процентная скидка действует на категорию или отдельные товары, а не на весь
  заказ, рубли не считаются: карточка пишет «Скидка на категорию», а точную сумму
  показывает корзина сервиса.
- Отметки «Сработало / Не сработало» меняют статус: много жалоб — код уходит из
  выдачи, подтверждения — поднимают.
- Популярность кода на сайте-источнике («применён N раз») не считается
  подтверждением: для кодов из фида в рейтинг идут только отметки пользователей.

Сборщик:

- отбрасывает аптеки, цветы, косметику, зоотовары и прочие непищевые разделы;
- вытаскивает города из условий и помечает коды с географическим ограничением;
- отбрасывает коды с истёкшим или неоднозначным сроком;
- объединяет одинаковые коды из разных источников и считает `confidence`;
- ведёт `data/state.json` (история) и `data/source-health.json` (здоровье источников);
- пишет `data/codes.json` без BOM, чтобы браузерный `JSON.parse` не падал.

Если сайт изменит разметку, соответствующий парсер в `collector.ps1` нужно
поправить. Список источников находится в начале скрипта (`$script:Sources`).

## Формат фида

`data/codes.json`:

```json
{
  "updatedAt": "2026-11-21T23:57:00+03:00",
  "generator": "PromoLov collector",
  "sources": [
    { "name": "promokod.com", "url": "https://promokod.com/coupon-store/eda-yandex-ru" }
  ],
  "codes": [
    {
      "service": "Яндекс Еда",
      "code": "EAT400",
      "type": "fixed",
      "value": 400,
      "maxDiscount": 0,
      "minOrder": 800,
      "freeDelivery": false,
      "deliveryCost": 149,
      "title": "Скидка 400 рублей при заказе от 800 рублей",
      "category": ["доставка еды", "собрано с сайта"],
      "conditions": ["Заказ от 800 ₽"],
      "expiresInDays": 41,
      "works": 2802,
      "fails": 0,
      "existingUsers": false,
      "wholeCart": true,
      "cities": ["Москва", "Московская область"],
      "cityRestricted": true,
      "collections": ["firstOrder", "wholeCart"],
      "sourceName": "promokod.com",
      "sourceUrl": "https://promokod.com/coupon-store/eda-yandex-ru"
    }
  ]
}
```

Обязательны только `service`, `code` и `type`. Остальное подставляется:

- `existingUsers` — `false`, если есть `"firstOrderOnly": true`, категория
  «первый…» или коллекция `firstOrder`; иначе `true`.
- `wholeCart` — из `collections` (`wholeCart`), иначе `true` для `fixed`/`percent`
  и `false` для `delivery`.
- `cities` — массив городов из условий; `cityRestricted` = `true`, если массив непустой.
  Пустой массив означает «все города».
- `sourceName` / `sourceUrl` — попадают в карточку и в детали кода.
- `collections` — `firstOrder`, `returning`, `wholeCart`; удобно для явной
  привязки к подборкам.

Можно отдать и просто массив кодов. Пример — `data/feed.example.json`.

### Кэш

Успешно загруженный фид сохраняется в `localStorage` под ключом
`promolov.feedCache.v1` вместе с URL и временем загрузки. При старте приложение
сначала показывает кэш, затем пытается обновить его из сети. Если сеть недоступна,
коды остаются на экране. Сброс прогресса в панели «Источники» очищает и кэш.

## Как считается выгода

Для кода берётся ориентировочный чек `max(1200, минимальный чек)`:

- скидка: `percent` → чек × % (с лимитом), `fixed` → номинал, `delivery` → 0;
- доставка: если `freeDelivery`, добавляется `deliveryCost`;
- `roi = (скидка + доставка) / чек`;
- надёжность = сглаженная доля успешных срабатываний;
- свежесть = затухание по дням с момента проверки.

```
score = 100 × (0.50 × min(roi / 0.35, 1) + 0.28 × надёжность + 0.17 × свежесть + 0.05 × срочность)
```

В карточке при вашем чеке показывается не индекс, а конкретная экономия в рублях.

## Ограничения и честность

- Коды собираются с публичных страниц агрегаторов и могут устареть или не
  сработать: окончательные условия всегда на сайте сервиса.
- «Рабочий» — это уверенность по источнику и отметкам, а не гарантия срабатывания:
  код может не примениться из-за региона, аккаунта, ресторана или других условий.
- Процентные скидки на отдельную категорию не переводятся в рубли: точная сумма
  зависит от состава корзины.
- Фильтр «Только рабочие» по умолчанию скрывает демо-коды, если загружен реальный фид.
- Сборщик не обходит капчи, авторизацию и `robots.txt`; при изменении разметки
  парсер может перестать находить коды.
- Демо-коды из `assets/data.js` вымышлены и нужны только для демонстрации.
  В карточке они помечены «демо», а в деталях написано, что акция не действует.
  Реальные коды приходят из `data/codes.json` и помечены источником.
- Проект не связан с Яндекс Едой, Ozon, Самокатом и другими сервисами.
- LAN-сервер доступен всем устройствам в вашей сети на порту 8787. Не запускайте
  его в недоверенной сети и закрывайте окно сервера, когда доступ не нужен.
- Публичная ссылка открывает сайт любому, у кого она есть. Останавливайте туннель
  (`Ctrl+C`), когда он больше не нужен; бесплатный адрес периодически меняется.
